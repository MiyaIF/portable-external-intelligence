# Contributor Covenant Code of Conduct

## Our standards

We are committed to a welcoming, respectful, and technically rigorous community. Participants must act professionally, respect different viewpoints, accept constructive feedback, and focus criticism on ideas and behavior rather than people.

Harassment, discrimination, threats, doxxing, impersonation, malicious disclosure of private data, and deliberate introduction of secrets or unsafe code are not acceptable.

## Enforcement

Report conduct concerns privately to the maintainers through the repository owner's public GitHub profile or an appropriate private GitHub channel. Do not include passwords, tokens, raw transcripts, client data, or other sensitive material.

Maintainers may remove content, request a correction, restrict participation, or close contributions when necessary to protect participants or the project. Decisions are made case by case. This document does not promise a response SLA.
