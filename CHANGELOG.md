# Changelog

All notable changes to this project are documented here.

## [1.0.0] - Unreleased

- Initial public-release candidate for the portable external-intelligence engine.
- Three-root separation for public engine, private knowledge, and local runtime.
- CLI-agent hooks, privacy gates, migration/rollback receipts, dependency locks, and release evidence contracts.
- Setup-created virtual environments now bootstrap the engine without `PYTHONPATH`, including after update and from Unicode clone paths.
- Selected subscription CLI hosts now provide bounded structured inference through safe native or standard npm launchers.
- Setup diagnostics now reload the committed manifest before reporting provider and experiment state.
- Windows scheduled-task registration now uses valid repetition and interactive-principal contracts.
- Git synchronization now ignores line-ending/stat-only changes, recovers owned stale worktrees, removes temporary worktrees through Git before safe fallback cleanup, and reports cleanup failures to the scheduler.
- Projection rebuilds now preserve semantically identical files and remove only outputs that became stale, preventing Windows line-ending-only dirty states.
- Personal knowledge is now explicit, with an optional empty team event store, merged bounded recall, separate status/retention reporting, and offline-deferred team maintenance.
- Setup reruns are manifest-reconciled and non-destructive: identical selections report `ALREADY_CURRENT`, managed conflicts are preserved, and default update/uninstall retain personal/team data.
- Real-host activation and longitudinal A/B effect validation remain separate evidence gates.
